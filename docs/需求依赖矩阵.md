# 外卖吃啥 v0.1.0 · 需求依赖矩阵

## 当前决策

- 产品：免登录、免授权的外卖决策工具，打开网页就能用。
- 版本：v0.1.0。
- 技术：原创单文件 HTML，原生 CSS / JavaScript，无框架、无构建、无后端依赖。
- 交付：在线网页 + `zhoujinq/what-to-eat` 完整 GitHub 仓库。
- 方法：MVP 纵向闭环 + TDD，不采用阶段签核式瀑布流程。
- 独立性：参考产品只用于提炼行为与规则；不复用其代码、图片、字体、账号体系或后端。

## 证据来源

1. 用户提供的本地参考壳：`参考-同事做的——健康餐转盘.html`。它只有平台运行时和远端模块入口，直接打开空白，不能作为独立产品继续维护。
2. 逆向分析报告：https://g97aoekjur.feishu.cn/docx/VHKSdawm8oErd2xsAKYc9XvRnic 。保留无放回随机袋、结构化菜库、先选结果再播动画三个行为。
3. 旧规划：https://g97aoekjur.feishu.cn/docx/JjKIdUtuwoTjhlx510Qcwaxhnxe 。仅采纳免授权、单文件、历史与文本复制等适合本轮 MVP 的内容；其“通用决策工具”和瀑布阶段门不作为本轮约束。
4. 用户当次指令：当前项目就是垂直的“外卖吃啥”，先做 v0.1.0 并实际上线。

## 依赖矩阵与验收

| 顺序 | 需求 | 依赖 | v0.1.0 验收 |
|---|---|---|---|
| M0 | 独立页面壳 | 无 | 直接打开不空白；无外部 JS 也能完成核心流程；版本可见 |
| M1 | 默认菜库与筛选 | M0 | 至少 12 项；预算、口味、品类组合筛选；可恢复全部 |
| M2 | 公平抽取核心 | M1 | Fisher–Yates 无放回袋；一轮不重复；重洗有提示；避免跨轮连续重复 |
| M3 | 转盘与结果一致 | M2 | 先确定结果，再计算落点；每个扇区落点与结果一致；动画中禁止重复提交 |
| M4 | 结果动作与历史 | M3 | 再转一次、复制结果、确认“就吃这个”；最近记录可回看和清空 |
| M5 | 自定义菜库 | M1 | 新增、启停、删除自定义项；非法输入有人话提示 |
| M6 | 本地持久化 | M4、M5 | 刷新保留菜库、历史与设置；损坏存档自动回退，不白屏 |
| M7 | 移动与无障碍 | M0–M6 | 390px 无横向溢出；按钮可键盘操作；焦点可见；减少动态效果生效 |
| M8 | 公开交付 | M0–M7 | 自动化测试通过；真实浏览器验收；在线发布完成；GitHub 含源码、测试与文档 |

## MVP 非目标

- 不做飞书登录、微信登录或任何授权流程。
- 不做飞书提醒、真实外卖平台下单、实时商户价格与配送承诺。
- 不做后端账号、云端同步、分享码服务、小程序、营养热量体系。
- 不复制参考产品的品牌菜单、服务端接口、监控埋点或平台运行时。

## 设计计划

### 色彩

- 米纸 `#F6F1E7`：页面底色。
- 墨黑 `#202721`：正文。
- 森林绿 `#235446`：主按钮与当前状态。
- 蛋黄 `#F2C14E`：转盘焦点与结果高亮。
- 番茄 `#C4513F`：少量警示和删除动作。
- 灰绿线 `#D4D8CF`：小票分隔与结构线。

### 字体

- `Noto Sans SC`：中文正文与控件，系统字体完整回退。
- `Noto Sans Mono`：价格、时间和版本号；等宽字体不承载中文长正文。

### 布局

桌面以“左边决策信息、右边转盘”为一条主轴；手机把转盘和主按钮放在最前，筛选、结果、历史和菜库随后。

```text
桌面：
品牌 / 版本
┌───────────────┬────────────────┐
│ 简短说明      │                │
│ 筛选          │   决策转盘     │
│ 结果小票      │   转一下       │
└───────────────┴────────────────┘
最近决定 / 我的菜库

手机：
品牌 / 版本
决策转盘 + 转一下
结果小票
筛选
最近决定
我的菜库
```

### 独立性与克制

识别度来自“转盘 + 外卖小票”，不是通用渐变卡片墙。动画只在用户主动抽取时出现；减少动态效果开启时直接显示结果。参考产品的绿色并不构成可保留资产，本轮重新建立色彩、排版、数据与代码。

## 回滚与公开边界

- 新项目，无旧用户数据、旧流量或生产接口需要迁移。
- 默认数据是通用菜品与估计价格/时间，不代表真实商户承诺。
- 所有个人改动仅存浏览器 localStorage；清理浏览器数据会删除这些改动。
- 发布前运行源码、算法、交互、移动端和资源检查；线上与 GitHub 分别核验，不混为一件事。
