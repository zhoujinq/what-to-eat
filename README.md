# 外卖吃啥 · what-to-eat

**v0.1.0：今天别纠结，转一下就开饭。**

一个完全独立、免登录、免授权的外卖决策网页。按预算、口味和品类筛选候选，用 Fisher–Yates 无放回随机袋公平抽取；转盘只是仪式感，结果先于动画确定。

## 直接使用

- 在线网页：https://g97aoekjur.doubao.link/app/app_17jfe4y3dsw
- GitHub：https://github.com/zhoujinq/what-to-eat
- 本地：直接双击 `index.html`，无需安装依赖或启动服务。

## v0.1.0 已实现

- 12 道原创默认候选，包含估计价格、送达时间、品类、口味和食用备注。
- 预算、口味、品类组合筛选，以及无候选空态和一键恢复。
- Fisher–Yates 洗牌、一轮无放回、抽完明示重洗、避免跨轮连续重复。
- 先确定结果，再计算转盘落点；支持减少动态效果偏好。
- 结果小票、再转一次、复制结果、“就吃这个”确认状态。
- 最近 8 条抽取历史，可清空。
- 自定义菜新增、启停、删除；默认菜也可启停。
- 菜库、筛选、历史、随机袋和转盘角度保存在当前浏览器 localStorage。
- 损坏存档自动回退，页面直接以 `file://` 打开也可运行。
- 桌面双栏、手机单栏；真实视口检查无横向溢出。

## 明确不做

本版不接飞书/微信登录，不做云端同步、分享码、飞书提醒、真实下单、实时商户价格、小程序或营养热量系统。默认价格和时间是通用估计，不是商户承诺。

## 本地开发

无需构建，无运行时依赖。编辑 `index.html` 即可。

```powershell
# 可选：启动本地静态服务
npm run serve

# 运行核心算法与结构测试
npm test
```

测试要求 Node.js 18+。本地服务默认地址为 `http://127.0.0.1:4173`。

## 测试与验收

- `tests/app.test.js`：16 条 Node 原生测试，覆盖筛选、随机袋、跨轮防重、转盘落点、边界抖动、自定义菜、历史、存档和复制文本。
- `tests/responsive.html`：独立 iframe 视口验收页，通过 `w`、`h`、`scale` 查询参数检查桌面和手机布局。
- `docs/验收记录.md`：v0.1.0 的真实浏览器验收与发布记录。
- `docs/需求依赖矩阵.md`：MVP 范围、依赖顺序、设计计划、公开边界和非目标。

响应式验收示例：

```text
http://127.0.0.1:4173/tests/responsive.html?w=1280&h=900&scale=0.52
http://127.0.0.1:4173/tests/responsive.html?w=390&h=844&scale=0.78
```

## 核心规则

随机袋先保存候选 ID 的洗牌队列，每次取出一项；队列空了才重洗。若重洗后的首项与上一结果相同且候选大于 1，则与队列内另一项交换。

转盘 SVG 的扇区从顶部开始绘制。选中结果后，根据扇区中心、当前角度和不超过扇区宽度 ±25% 的抖动计算最终角度，再加四整圈。只旋转内部 `wheelRotor`，避免旋转外框造成手机横向溢出。

## 数据与隐私

所有个人改动只存当前浏览器，不上传菜库或历史，不采集账号信息。清理浏览器数据会删除个人改动；换设备不会自动同步。字体使用自托管镜像，字体加载失败时有完整系统字体回退，核心功能不依赖外部 JavaScript。
